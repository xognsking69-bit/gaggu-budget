# 가꾸 가계부 v4 — 기능 완성형 베타

GitHub 저장소: `gaggu-budget`

## 이번 버전에서 한 번에 완성한 기능
- 달력 날짜별 수입/지출 및 자동 합산
- ⚡ 빠른 지출 입력
- 월 총수입 / 총지출 / 잔액
- 월 전체 예산
- 카테고리별 예산 직접 설정
- 카테고리 예산 80% 주의 / 100% 초과 표시
- 고정비 관리 + 매달 자동반영
- 구독 관리 + 매달 자동반영
- 저축 목표 / 진행률
- 월간 소비 리포트
- 전월 대비 소비 비교
- 최근 6개월 지출 흐름
- 소비 리포트 PNG 이미지 실제 저장
- 연간 12개월 지출 그래프
- 연간 수입 / 지출 / 잔액 / 월평균 지출
- 연간 카테고리별 지출
- 날짜별 사진 저장 (IndexedDB)
- 사진 개수 달력 표시 / 크게 보기 / 삭제
- 테마 5종
- 달력 스타일 3종
- 배경 / 포인트 / 카드 색상 직접 선택
- 카테고리 이모지 직접 변경
- JSON 백업 / 복원
- 모바일 / 태블릿 / PC 반응형

## 저장 방식
일반 가계부 데이터: localStorage
사진: IndexedDB
사진은 JSON 백업에 포함되지 않으며, 추후 Cloudflare R2 등 서버 저장으로 확장할 수 있습니다.

## 배포
GitHub `gaggu-budget` 저장소 최상단에
- index.html
- styles.css
- app.js
를 올린 뒤 Cloudflare Pages로 배포합니다.

Trip꾸 / tripggu-auth / tripggu-admin 과 완전히 별개입니다.
