# 가꾸 가계부 v2

GitHub 저장소 추천 이름: `gaggu-budget`

## 포함 기능
- 달력 날짜 클릭 → 수입/지출 입력
- 날짜별 총 수입·총 지출 자동 합산
- 월 총수입·총지출·잔액·남은 예산
- 월 예산 설정 및 사용률
- 카테고리별 지출 통계
- 고정비 등록 및 이번 달 반영
- 날짜별 사진 여러 장 저장
- 사진 자동 축소 후 IndexedDB 저장
- 달력에 사진 개수 표시
- 포근 크림 기본 테마
- 딸기우유 / 라벤더 / 민트 / 하늘 테마
- 달력 스타일 3종
- 배경·포인트·카드 색상 직접 변경
- 카테고리 이모지 직접 변경
- JSON 백업/복원
- 모바일 / 태블릿 / PC 반응형

## 사진 저장 안내
사진은 현재 브라우저의 IndexedDB에 저장됩니다.
다른 기기와 자동 동기화되지 않으며 JSON 백업에는 사진이 포함되지 않습니다.
향후 Cloudflare R2 등 서버 저장 방식으로 교체하기 쉽게 별도 저장소 구조로 분리했습니다.

## 배포
`index.html`, `styles.css`, `app.js` 세 파일을 GitHub `gaggu-budget` 저장소 최상단에 올린 뒤
Cloudflare Pages 등 정적 호스팅으로 배포하면 됩니다.

Trip꾸 프로젝트와는 완전히 별개이며 `worker.js`는 포함하지 않습니다.
