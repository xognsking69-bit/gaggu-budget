# 가꾸 가계부 v4.1 — 폰 실사용 개선판

GitHub 저장소: `gaggu-budget`

## 이번 수정
- 휴대폰 가로화면 달력 오른쪽 잘림 개선
- 달력 금액이 길어도 셀 안에서 안전하게 표시
- 카테고리 예산 80% 도달: 화면 상단 경고 + 최초 팝업
- 카테고리 예산 100% 초과: 강한 경고 + 최초 팝업
- 지출/수입 선택 시 해당 종류만 즉시 버튼으로 표시
- 지출 종류 대폭 확대
  식비, 카페, 교통, 쇼핑, 생활, 고정비, 의료, 여가, 교육, 육아, 반려동물, 미용, 여행, 경조사, 보험, 세금, 대출, 기타지출
- 수입 종류 확대
  급여, 부수입, 용돈, 상여금, 환급, 이자, 중고판매, 기타수입
- 고정비 저장 즉시 이번 달 달력에 자동 반영
- 이후 매달 자동 반영
- '이번 달 반영' 버튼 제거
- 고정비 '해지' 버튼 추가
- 해지 후 과거 지출은 유지, 다음 달부터 자동반영 중단
- 저축 전용 메뉴 추가
- 저축하기 / 꺼내쓰기 / 현재 저축잔액 별도 관리

## 기존 유지
사진, 꾸미기, 월/카테고리 예산, 구독, 소비리포트 PNG, 저축목표, 연간통계, 백업/복원 등.
